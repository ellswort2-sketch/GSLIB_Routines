GAMV1 direct semivariogram · Browser-local calculations

From field records to experimental semivariograms

Upload raw yield, smoothed yield, or soil observations. Select projected coordinates, define distance classes and direction filters, and compare the resulting curves. Files stay in your browser.

This page implements direct semivariogram type 1, as requested by GV1.PAR, in 2D or 3D. Other GAMV measures and cross-variograms are not implemented. No model fitting or kriging is performed.

2 Set distance classes

Defaults reproduce the supplied GV1.PAR. Paths in a PAR file are informational; select your data file above.

GAMV1 writes nlag + 2 bins: an exact-zero bin, a near-zero distance bin, then the requested positive lags. Overlapping tolerances admit a pair to multiple bins. A nonpositive tolerance is reset to half the spacing.

3 Choose directions

Azimuth: 0° = north–south; 90° = east–west. This differs from the moving-average tool’s angle convention. Angular tolerances are half-angles; bandwidths are maximum perpendicular distances.

Dip follows the supplied code: positive values tilt toward positive Z. Azimuth or dip tolerance ≤0 becomes 45°, matching GAMV1. Azimuth tolerance ≥90° accepts all azimuth angles but bandwidth and dip filters still apply.

For 2D records (Z=0), the first two GV1.PAR filters are effectively the same. Its third filter selects a narrow north–south corridor. Use the field preset for an E–W/N–S comparison.

Read the pattern

The direct experimental semivariogram is γ(h) = Σ[v(i) − v(j)]² / [2N(h)]. Nearby observations that are similar give a small semivariance. Compare curves using the same lag settings, support, and normalization.

For your yield field, start with raw Yld Vol(Dr and then compare the moving-average estimates. Smoothing changes spatial continuity, so keep raw and smoothed results clearly labeled. Directional contrasts describe spatial structure; they do not identify the cause of that structure.

Source compatibility and limits

Implements the supplied type-1 pair selection, lag cutoff (nlag + 0.5 − ε) × spacing, azimuth/dip filters, bandwidths, self pairs, omni reversal counts, means, and population-variance normalization. Uses JavaScript double precision. The supplied GAMV1.INC sets ε=10⁻²⁰; this adaptation uses that same constant. It is numerically tested, but not a bit-for-bit Fortran executable comparison. Empty bins are blank instead of the source’s zero-filled output. Valid values use the consistent reader rule minimum ≤ value < maximum. The original pair loop’s occasional inclusive upper-bound behavior for multivariable data is not reproduced.

One direct variable per run; no types 2–10, residual covariance, indicators, or automatic sampling. At most 15,000 valid records (about 112.5 million unordered pairs). Computation runs in a cancelable Web Worker. Data and results are not retained after a page reload.
