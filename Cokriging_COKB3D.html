Cokriging

Estimate a primary soil or yield variable using its observations and one or two secondary variables. Adapted from COKB3D.F and the supplied GSLIB library.

1 · Primary and secondary observations

Use one CSV or GEO-EAS table containing coordinates and variable columns. Primary and secondary values can occur at different locations: leave an unavailable value blank in CSV, or use an out-of-trim sentinel such as −999 with trimming minimum 0. The first selected variable is the one estimated.

A blank primary value does not discard a row with useful secondary data. Coordinates must be in a verified linear coordinate system. Every variable has its own units; direct coefficients have squared variable units and cross coefficients have the product of the two variable units. Means are required for SK and mean-adjusted OK. Traditional OK is invariant to the means.

PAR import loads field positions, grid, searches, means, direct/cross models, and selects source compatibility. File paths do not open local data automatically.

2 · Linear model of coregionalization

Nugget covariance matrix

How to specify a valid joint model

Each shared structure has one model type, anisotropy, and range set. Its symmetric coefficient matrix contains direct variances on the diagonal and cross coefficients off the diagonal. Every nugget/structure matrix must be positive semidefinite; the page checks the full matrix, not just pairwise correlations.

Separate univariate fits alone do not define the cross model. Use direct and cross-variogram evidence to choose a defensible joint model. Cross coefficients can be negative if the full matrix remains valid. Spherical, exponential and Gaussian structures are supported; power and hole-effect covariance models are excluded from this browser LMC implementation.

Gaussian uses the supplied COVA3 convention exp(−9(h/a)²). Search and model azimuth are 0° north–south and 90° east–west. Dip is positive downward.

3 · Searches and source conventions

Recommended mode uses independent primary/secondary searches, enforces the minimum on primary observations, and calculates variance from the full kriging right-hand side. Source compatibility uses the primary search for both, tests the minimum against all observations, and reproduces the source’s unscaled subtraction of Lagrange multipliers in the variance. Estimates can agree while reported variances differ. Negative variance is flagged explicitly.

The source’s collocated-cokriging flag is not implemented and stops the original program. Use explicit secondary observations at their coordinates here. Secondary maxima apply across all secondary variables combined, not separately.

4 · Estimation grid and support

Block discretization

1 × 1 × 1 gives point support. More points approximate a block average over the cell dimensions, up to 64 points. Grid origin is the first cell center, with X varying fastest. Clip the exported grid to your field boundary in QGIS.
