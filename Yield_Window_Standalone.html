3 Choose the neighborhood

Window dimensions are distances, not a fixed number of records or passes. Every retained observation in the window receives equal weight for the arithmetic mean. Unequal sampling density can therefore affect the estimate.

Enter a name for this run. Both downloads use the same name; extensions are added automatically. Changing this name does not rerun the calculation.

CSV fields: node_id, x, y, yield_estimate, population_variance, n, status. Blank estimates mark unsupported nodes. Variance is the unweighted within-window population variance, including in weighted mode; it is not prediction uncertainty.

Use the result in QGIS

  1. Download the grid CSV.
  2. Open Add Delimited Text Layer.
  3. Choose X = x, Y = y, and the same verified CRS used here.
  4. Style yield_estimate with graduated symbols. Inspect n before interpreting patterns.

Estimated yield patterns are an exploratory input for comparing soil and yield; they do not alone establish fertilizer requirements or persistent production zones.
