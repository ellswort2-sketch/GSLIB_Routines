Spatial Analysis Tools

Choose a program below. Each tool opens as its own page, with a navigation menu at the top to return here or switch programs.

01 · SUMMARIZE LOCAL PATTERNS

Yield moving average

Estimate local average yield within a rectangular or elliptical moving window.

Input
Yield observations with coordinates; CSV or supported shapefile/DBF inputs.
Output
Estimates at regular grid nodes, uploaded nodes, or yield locations, with neighbor counts.
Open yield moving average →
02 · EXAMINE SPATIAL CONTINUITY

Experimental variogram

Calculate how differences in soil properties or yield change with separation distance and direction.

Input
CSV or GEO-EAS observations with coordinates and a selected variable.
Output
Experimental semivariances, pair counts, directional plots, and downloadable results.
Open experimental variogram →
03 · FIT THE SPATIAL MODEL

Variogram fitting

Fit bounded nested models to experimental lag data, with weighted least squares and joint directional fitting.

Input
Experimental lag distances, semivariances, and optional pair counts.
Output
Fitted coefficients and ranges, residuals, and a model export for kriging.
Open variogram fitting →
04 · ESTIMATE BETWEEN SAMPLES

Kriging

Use the KT3D kriging methods to estimate soil properties or yield at selected locations.

Input
Observations, a specified variogram model, and an estimation grid or target nodes.
Output
Kriging estimates, variance, standard deviation, and validation statistics.
Open kriging →
05 · INCORPORATE SECONDARY DATA

Cokriging

Estimate a primary variable using its observations and related secondary variables.

Input
Primary and secondary observations with coordinates and a valid joint covariance model.
Output
Primary estimates, uncertainty, and neighborhood counts.
Open cokriging →

Suggested classroom workflow

  1. Prepare the data. Verify coordinates and units, remove harvest artifacts, and select the variable to analyze.
  2. Explore spatial patterns. Use the moving average where appropriate, and calculate variograms for the data you intend to model. Soil observations can go directly to the variogram tool.
  3. Choose and evaluate a model. Use variogram fitting to evaluate model parameters, then check kriging cross-validation before estimating at grid nodes. Use cokriging when a defensible joint primary/secondary covariance model is available.
  4. Return to QGIS. Map the exported estimates with the original CRS and compare them with field boundaries and soil information.

Use consistent distance units. The experimental variogram tool calculates lag statistics; the fitting tool estimates model parameters. Cokriging additionally requires direct and cross-covariance models. These tools process files in your browser.
